# 📊 Projeto de Análise de Dados com Pandas

Este projeto foi desenvolvido como parte do bootcamp da DIO para consolidar conhecimentos em **Pandas**, **limpeza de dados**, **estatísticas básicas** e **visualização de dados**.

## 🚀 Tecnologias Usadas

- Python 3.x
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📁 Estrutura

- `/data`: arquivos CSV ou Excel usados
- `/notebooks`: arquivos `.ipynb` com o passo a passo da análise
- `/assets`: imagens dos gráficos, prints dos outputs

## Dataset

O dataset utilizado neste projeto contém informações sobre o consumo de açúcar per capita em diversos países. Os dados incluem informações como o nome do país, consumo médio de açúcar por pessoa e ano de coleta. O objetivo é realizar uma análise exploratória e gerar insights sobre os padrões de consumo de açúcar no mundo.

## 🧼 Etapas da Análise

1. **Importação dos Dados**
2. **Limpeza e Tratamento de Dados**
3. **Análise Exploratória (EDA)**
4. **Visualização de Insights**
5. *(Opcional)* Exportação dos dados tratados
